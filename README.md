📊 Simulador de Investimentos e Renda Passiva

📌 Sobre o projeto

Este projeto consiste em uma planilha desenvolvida no Gnumeric para simular investimentos mensais, acompanhar a evolução do patrimônio e estimar a geração de renda passiva por meio de dividendos.

A planilha permite configurar informações financeiras pessoais, definir um valor mensal para investir e visualizar projeções de patrimônio em diferentes períodos. Também apresenta uma sugestão de distribuição dos aportes entre diferentes tipos de Fundos de Investimento Imobiliário (FIIs).

O objetivo é facilitar o planejamento financeiro de longo prazo, ajudando a visualizar como a constância nos aportes e os rendimentos podem contribuir para a construção de patrimônio.

⚙️ Funcionalidades

1. Configurações financeiras

A primeira seção permite definir os parâmetros utilizados na simulação:

    Salário: R$ 7.000,00.
    Rendimento da carteira: 0,60%.
    Sugestão de investimento: 30% da renda, equivalente a R$ 2.100,00.

Esses valores servem como referência para o planejamento financeiro e podem ser ajustados conforme os objetivos do investidor.
2. Simulação de investimento mensal

A segunda seção apresenta os parâmetros principais da simulação:

    Aporte mensal: R$ 2.000,00.
    Período de investimento: 5 anos.
    Taxa de rendimento mensal: 1,08%.
    Patrimônio acumulado: valor projetado para o período configurado.
    Dividendos mensais: estimativa de renda passiva gerada pela carteira.

3. Projeções de patrimônio e dividendos

4. Distribuição dos investimentos em FIIs

A última seção apresenta uma sugestão de alocação do aporte mensal entre diferentes segmentos de Fundos de Investimento Imobiliário.

Considerando um aporte de R$ 2.000,00, a distribuição exibida é:
Tipo de FII	Percentual	Valor mensal

🛠️ Tecnologias utilizadas

    Gnumeric: software de planilhas utilizado para desenvolver e visualizar o projeto.
    Fórmulas de planilha: para realizar cálculos e estimativas financeiras.
    Microsoft Excel (.xlsx): formato utilizado para armazenar o arquivo da planilha.
